# Attention Span

Get fluent in AI, four minutes a day. An installable web app: open the link in Safari on an iPhone, tap Share, then Add to Home Screen.

**Open it:** https://akashdas7672-jpg.github.io/attention-span/

The files at the top of this repository are the built app that GitHub Pages serves. The source (app code, lessons, tools and full notes) is in [`source/`](source/README.md). To rebuild, run `node tools/build.mjs` inside `source/` and copy `source/dist/` to the top level.

Lessons are adapted in part from Google DeepMind's open course materials (CC BY 4.0 and Apache 2.0). Not an official Google product.
