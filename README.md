# Attention Span

A Duolingo-style daily course on how modern AI works, built from Google DeepMind's
[ai-foundations](https://github.com/google-deepmind/ai-foundations) and
[educational](https://github.com/google-deepmind/educational) notebooks.

Open the site in Safari on an iPhone and tap Share → Add to Home Screen. It runs full screen and offline.

Lesson content is adapted from the DeepMind materials (CC BY 4.0 and Apache 2.0). Not an official Google product.
